## 第二轮（退款/更正，已完成，纳入 v1.4.0）

- 新服务 `adjust_service_bill`，原账单唯一 ID 关联；部分/全额退款不得超过更正后剩余净额；更正填正确的原付款总金额，新增差额，不覆盖原账单。
- 请求编号必填、持久化去重、冲突拒绝、并发写锁保护；调整日期不得早于原付款/已有调整或晚于今天，原因必填，金额最多两位小数。
- 在 options 按需新增 `service_adjustments`；净额参与原账期费用和累计净投入，不将退款另计为退款月负运行费用。不自动退订或撤回服务覆盖，不修改套餐月费。
- 已有退款的账单拒绝金额更正；调整流水本身暂不支持撤销/更正，旧未追踪费用不支持直接冲销。
- 中文表单、账单关联展示、CSV 正负金额和原账单 ID 已完成；手机模拟验证更正、部分退款、断线重试不重复。
- 自动回归：76 项 Python、11 项前端测试通过，包含真实 HA fixture 的服务注册、reload 重试与实体标识保持。用户实际 HA 已安装测试版并于 2026-10-03 确认验收。
- 下一步：发布 v1.4.0；维修/保修与耗材低余量提醒后续开发。
