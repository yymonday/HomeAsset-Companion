## 自动验收

- 完整回归：55 passed。覆盖旧数据迁移、实体注册、Config/Options Flow、共享资源、服务调用、reload/unload 和上传接口。
- 订阅账期：提前多期续订保留当前费用，到下一期起始日切换；累计投入在付款时增加。
- 付款去重：同一请求编号并发或重启后重试仅记一笔，编号对应不同内容时拒绝；旧未提供编号的调用仍兼容。

## 实机验收：待提供访问入口

升级前创建 HA 备份。通过 HACS 安装 v1.3.0 并重启 HA，将仪表盘资源版本参数更新为 `?v=1.3.0`，再刷新浏览器。

1. 原记录可加载，原 entity_id、unique_id、累计金额、子项目与图片不变。
2. 中文表单可打开、切换类型及取消；账单日期、金额、备注和覆盖期限正确。
3. 用独立测试订阅验证提前续订及同笔重试，不对实际订阅重复登记费用。
4. 在测试订阅设置中开启到期提醒，确认站内通知可见，reload/重启不重复发送同一阶段。
5. 关闭提醒或取消测试订阅后不再发送；续订后的新到期日重新计算。
6. 手机端可操作，日历中的全天到期事件日期正确。

手机推送需另配 HA 自动化，v1.3.0 内置提醒使用站内通知。
