# v1.4.0 · 账单导出与纠错

本版增加订阅账单 CSV 导出、退款登记与金额更正，并完善无到期日服务的记账入口和卡片布局。测试版及 UI 修复已于 2026-10-03 获得用户实机验收确认。

## 新功能

- **本地 CSV 导出**：在“账单明细”导出首次付款、续订、附加支出与调整记录，包含中文表头、金额、日期、覆盖期限、原因和原账单 ID。文件在浏览器本地生成。
- **退款登记**：支持多次部分退款或全额退款，累计不得超过原账单更正后的剩余净额。
- **金额更正**：填写正确的原付款总金额，保留原账单并新增差额。例如 280 元更正为 250 元，新增 -30 元调整。
- **无到期日记账**：有效的无到期日或永久服务也能通过“记一笔”登记附加支出。

## 体验与兼容

- 延续原卡片配色、圆角与轻阴影；记账及续订按钮内容居中、桌面高度收紧，窄屏自动分行，触屏保留易点击的高度。
- 旧订阅缺少新版付款明细时不再显示“付款覆盖未追踪”；已记录付款的覆盖日期与到期日不一致时仍提供核对提示。
- 调整请求持久化去重并进行并发保护；金额最多两位小数，原因必填，日期不能早于原付款或已有调整，也不能晚于今天。
- 调整后的净额用于累计投入和原账期费用，不改变原到期日、覆盖期限或套餐参考月费；原账单和实体 ID 保持不变，Config Entry schema 仍为 V2。

## 升级

1. 创建 Home Assistant 备份，通过 HACS 更新至 v1.4.0，然后重启 HA。手动安装时使用本版本源码中的 `custom_components/device_companion`。
2. 将现有仪表盘资源的版本参数改为：
   - `/device_companion/device-companion-card.js?v=1.4.0`
   - `/device_companion/device-companion-summary.js?v=1.4.0`
3. 刷新浏览器。已安装 `1.4.0b1` 或 `1.4.0b1-ui2` 卡片的用户也按上述步骤升级，无需重新创建记录。

## 使用边界

- 退款仅记录已收到的款项，不向订阅平台发起退款，也不会自动取消服务。
- 已有退款的原账单不能再更正金额，调整流水暂不支持撤销。旧无付款明细的累计投入不支持直接调整。
- CSV 用于账单查看，不是配置恢复备份。产生调整后降回 v1.3.0，旧版不会计算调整净额，应保留完整 HA 备份。
