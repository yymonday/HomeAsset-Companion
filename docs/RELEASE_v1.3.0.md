# v1.3.0 · 账单与到期提醒

本版完善订阅记账体验，并修复提前续订时下一期费用立即覆盖当前成本的问题。

## 新功能

- **账单明细**：按付款日期展示首次付款、续订、升级差价和额外额度，续订显示覆盖期限。
- **中文记账表单**：填写实际付款日期、金额与覆盖月数，支持升级月费、取消及失败重试。仅登记已付款项，不会向外部平台扣款。
- **到期提醒**：在集成“修改基础资料”中开启，HA 本地 09:00 提前 7 天、3 天及当天发送站内通知。默认关闭，重载/重启保留去重标记。

## 稳定性与兼容

- 提前续订保留当前账期，下一期在覆盖起始日生效，累计投入在付款时增加。
- 付款请求编号持久化去重，拒绝同编号不同内容；旧自动化如需重试保护，应为每笔付款提供稳定的 `request_id`。
- 服务写锁跨 reload 保持稳定，日历查询使用 HA 本地时区，拒绝 NaN/Infinity 金额。
- Config Entry schema 保持 V2，原实体及项目 ID 不变，不自动补造旧付款明细。

## 升级

1. 先创建 Home Assistant 备份，通过 HACS 更新后重启 HA。
2. 仪表盘资源更新为：
   - `/device_companion/device-companion-card.js?v=1.3.0`
   - `/device_companion/device-companion-summary.js?v=1.3.0`
3. 刷新浏览器，检查原记录与账单；需要提醒时在对应订阅设置中开启。

## 验证

55 项自动测试通过；Python/前端语法、JSON/YAML 和 diff 检查通过。内置浏览器验证手机布局、取消及连接中断后的同笔重试。
